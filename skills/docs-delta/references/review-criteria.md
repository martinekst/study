# Comparison review criteria

- The requested scope and both comparison sides are explicit.
- Every gap or contradiction cites the documented claim and the competing
  evidence at a reproducible location.
- Missing evidence is not presented as proof that behavior is absent.
- Findings distinguish documentation drift, implementation drift, uncovered
  behavior, and intentionally excluded scope.
- Proposed repairs name the canonical owner and do not silently change the
  persistent README contract.
- Stable IDs and priorities remain consistent when the comparison is rerun.
