# FF – Metodika doménových modelů a diagramů

Doménový model musí obsahovat:

1. Diagram v PlantUML
2. Tabulkový přehled entit a číselníků

Používej vzory (v tomto adresáři):

- `vzor-domain-model-plantuml.txt`
- `vzor-jak-na-domenove-modely.md`
- `vzor-domenovy-model-tabulky.md`

Dodržuj metodiku zápisu, datové typy, názvosloví, vazby a konzistentní pojmenování (detailní pravidla viz `vzor-jak-na-domenove-modely.md`).

## Preferované typy diagramů podle účelu

- doménový model → **class diagram**
- procesní logika → **activity diagram**
- integrace → **sequence diagram**
- architektura → **component diagram**
- životní cyklus entity → **state machine diagram**
