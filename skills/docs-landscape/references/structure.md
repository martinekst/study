# Landscape outputs

Use a dated snapshot folder outside the versioned portal tree unless the user
provides another established location.

- executive overview: portfolio purpose, key dependencies, material risks;
- inventory: repository/system, purpose, stack signals, lifecycle, evidence;
- interaction map: producers/consumers, interface/event, trust boundary;
- ownership/gaps: observed ownership signals and unknowns;
- impact analysis: affected systems, likely propagation, evidence confidence;
- machine-readable inventory only when another documented consumer needs it.

Do not turn an inventory into a second source of truth for service-owned detail.
