# Evidence and uncertainty

Resolve evidence per run and record only what was actually inspected.

| Lifecycle            | Preferred evidence                                                          | Required distinction                        |
| -------------------- | --------------------------------------------------------------------------- | ------------------------------------------- |
| Discovery            | interviews, proposals, research, existing process material                  | fact vs option vs unresolved question       |
| Implementation-ready | approved specification, decisions, acceptance criteria, interface contracts | agreed target vs unapproved alternative     |
| As-built             | code, configuration, schemas, deployed behavior, then existing docs         | implemented current state vs planned change |

When sources conflict, name both sources, describe the consequence, and create a
finding or explicit open point. Do not manufacture a resolution.

A page-level source note may be refreshed after a small verification. A portal-
wide verification statement is allowed only in a review report that lists the
complete scope and evidence reference.
