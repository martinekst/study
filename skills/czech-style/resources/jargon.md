# Jargon — correct Czech, wrong industry

The reader of a TechFides offer is usually a CFO, a majitel, or a COO —
not a developer. Vocabulary that is invisible inside a software team is
conspicuous to them, and it signals that the document was assembled
from a template rather than written for them.

## Replace

| Žargon                        | Náhrada                                       | Proč                                                                        |
| ----------------------------- | --------------------------------------------- | --------------------------------------------------------------------------- |
| bolesti (pain points)         | problémy, slabiny, úzká místa                 | doslovný překlad, mimo IT zní jako z ordinace                               |
| karta (initiative card)       | detail, přehled, list                         | „karta" evokuje kartotéku                                                   |
| deep dive                     | hloubkový rozbor                              |                                                                             |
| quick win                     | rychlý přínos, levný krok s okamžitým efektem |                                                                             |
| filtr (na otázky, na oblasti) | na co se ptáme, podle čeho vybíráme           | kalk z „the filter we apply"; česky se filtr nasazuje na data, ne na otázky |
| low-hanging fruit             | nejsnáze dosažitelné přínosy                  |                                                                             |
| best practice                 | osvědčený postup                              |                                                                             |
| workshopovat                  | uspořádat workshop                            | sloveso neexistuje                                                          |
| odeskalovat, eskalovat        | předat výše, řešit s vedením                  | v provozní dokumentaci lze ponechat                                         |
| iterovat nad něčím            | postupně upřesňovat                           |                                                                             |
| scopovat                      | vymezit rozsah                                | „scoping" jako název fáze je v pořádku                                      |
| onboardovat                   | zaškolit, zavést                              |                                                                             |
| requirementy, requesty        | požadavky                                     |                                                                             |
| issue                         | problém, nedostatek                           |                                                                             |
| delivery                      | dodávka                                       | v interních textech ponechat                                                |
| ownership                     | odpovědnost, vlastnictví                      |                                                                             |
| governance                    | řízení                                        | výjimka: „governance IT" je zavedený termín                                 |

## Keep — the customer's own vocabulary

Replacing these is the opposite mistake. Using them proves the analyst
understands the client's trade:

- **Nemovitosti a development:** asset management, land development,
  property management, brownfield, due diligence, kolaudace, leasing,
  nájemní smlouva, indexace nájmu, service charge, portfolio.
- **Finance:** cash-flow, konsolidace, uzávěrka, valuace, NAV,
  kovenanty, business case, controlling, intercompany.
- **IT, kde neexistuje česká alternativa:** reporting, workflow,
  master data, dashboard, cloud.

Rule: **the customer's industry terms stay, the consultant's habits go.**

## Anglicismy — the test

Ask: would this word appear in the client's own annual report or
internal e-mail? If yes, keep it. If it appears only in supplier
presentations, replace it.

Borderline cases worth a decision instead of a reflex:

| Termín       | Rozhodnutí                                            |
| ------------ | ----------------------------------------------------- |
| stakeholdeři | ponechat — v českém projektovém řízení zdomácnělo     |
| roadmapa     | ponechat — „plán rozvoje" je delší a méně přesné      |
| scoping      | ponechat jako název fáze, ne jako sloveso             |
| workshop     | ponechat — běžné i mimo IT                            |
| review       | nahradit („revize", „posouzení") ve zákaznickém textu |
| output       | nahradit („výstup") vždy                              |
