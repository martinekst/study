# Learn from a documentation session

Use only when the user explicitly asks to improve the skills from observed
session behavior. This is maintainer work, not a portal generation phase.

Read [references/workflow.md](references/workflow.md). Distinguish a reusable
failure from project-specific preference or missing source material. Propose the
smallest correction at the actual rule owner, check all callers, and do not
modify skills merely because one output could have been worded differently.

Use [references/entry-decision.md](references/entry-decision.md) to present and
record one feedback decision, [references/change-types.md](references/change-types.md)
to select the correct rule owner, and
[references/validation.md](references/validation.md) before handoff.

When implementation is authorized, use the original skill-creator workflow and
validate affected skills and forward behavior.
