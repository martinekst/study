# Diagram review criteria

- The host text establishes every node, edge, state, and label.
- The chosen diagram type materially improves understanding.
- Current, proposed, and unknown elements are visually distinguishable.
- Labels are readable, terminology matches the canonical text, and a legend is
  present when notation is not self-evident.
- The diagram and host page make the same claim after either one changes.
- Links, source files, and rendering remain maintainable without duplicating
  business or technical rules inside the visual.
