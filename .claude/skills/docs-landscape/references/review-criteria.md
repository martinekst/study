# Landscape review criteria

- Scope and snapshot date are explicit.
- Inventory facts link to inspected repository/configuration evidence.
- Runtime interactions are not inferred solely from dependency declarations.
- Direction, protocol, data sensitivity, and confidence are clear where known.
- Ownership unknowns remain unknown rather than assigned by guess.
- Impact statements distinguish confirmed effect from investigation candidate.
- The overview is understandable before repository-level detail.
