# Traceable estimation

## Required chain

`documented scope → work item → effort range/point → dependency/risk → rate → price`

For each item capture:

- scope/evidence anchor;
- roles or work categories;
- estimate and unit;
- assumptions/exclusions;
- dependency and uncertainty;
- whether contingency is included.

Calculate subtotals and totals from one machine-checkable source. Keep blanks
distinct from zero. State currency, rate basis, tax basis, rounding, validity,
and what would trigger re-estimation.

Use ranges when uncertainty is material; false precision is not transparency.
